# HireAI Build Plan

## Step 1 – Foundation
Repository, environment, backend/frontend scaffolding.

## Step 2 – Authentication
User model, roles, registration/login/logout, protected routes and permissions.

## Step 3 – Jobs
Create/edit/publish/close jobs and public job browsing.

## Step 4 – Applications
Candidate profile, resume upload, application submission and status tracking.

## Step 5 – AI JD Features
JD briefing and editable JD generation.

## Step 6 – Resume Analysis
Resume extraction and JD-resume match analysis.

## Step 7 – Dashboards
Recruiter and candidate dashboards, filters and review workflow.

## Step 8 – Security and Testing
File validation, access controls, audit logs, API tests and edge cases.

## Step 9 – Deployment
Production database, environment variables, storage and deployment.
